No se crearon seis páginas vacías ni seis repositorios con nombres supuestos. Cuando se reciban los perfiles, crear proyectos privados separados en la cuenta verificada, con nombre descriptivo por persona y exportación estática independiente. Confirmar el dominio/ruta antes de grabar las tarjetas; la URL de un repositorio GitHub no es la URL web de la tarjeta.

Las actualizaciones del contenido no necesitan regrabar una tarjeta si su dirección web se conserva. Mantener la ruta permanente bajo el dominio que gestione CLEMI facilita trasladar los archivos entre alojamientos.
